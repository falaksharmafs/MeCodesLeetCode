# [Count Substrings Starting and Ending with Given Character](https://leetcode.com/problems/count-substrings-starting-and-ending-with-given-character/)

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

**Topics:** Math, String, Counting

---

You are given a string `s` and a character `c`. Return _the total number of substrings of _`s`_ that start and end with _`c`_._

 

**Example 1:**

**Input: **s = "abada", c = "a"

**Output: **6

**Explanation:** Substrings starting and ending with `"a"` are: `"abada"`, `"abada"`, `"abada"`, `"abada"`, `"abada"`, `"abada"`.

**Example 2:**

**Input: **s = "zzz", c = "z"

**Output: **6

**Explanation:** There are a total of `6` substrings in `s` and all start and end with `"z"`.

 

**Constraints:**

	- `1 <= s.length <= 105`

	- `s` and `c` consist only of lowercase English letters.
